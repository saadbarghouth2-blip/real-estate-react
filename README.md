# 🏠 Real Estate Interactive Map (React)

A modern, responsive real estate map dashboard built with React + Leaflet.

### 🚀 Features
- Display properties on a map
- Filter by type (Apartment, Villa)
- Sidebar with property cards
- Responsive, elegant layout using TailwindCSS

### 🧰 Tech Stack
- React + Vite / CRA
- Leaflet.js for mapping
- TailwindCSS for styling

### 📦 Run locally
```bash
npm install
npm run dev
```
